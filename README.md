# Luck be a Landlord

**一个以概率结算为核心、以租金为约束的增长模型。**

对局从一个 5×4 的格阵开始。玩家向符号池中投入符号——硬币、猫、兔子、金矿、产蛋的家禽——每次拉动转盘，符号按各自规则结算金币，全部产出用于支付当期租金。租金无法支付，对局终止。

这套规则在形式上接近老虎机，实质是一个关于复利的增长模型，以及一个关于位置的价值分配问题。

## 对局结构

**位置决定产出，但位置不由玩家布置。** 每转抽到哪些符号、落在哪一格，都由洗牌决定；玩家不能拖动棋盘上的符号。唯一能改变位置的机制是稀有道具「交换装置」：每转停盘之后、结算之前，可以交换两个符号，每转一次，也可以放弃。结算沿邻接关系传播：乘数符号将增益传递给相邻符号，相邻符号的增益继续向外扩散。因此"把 19 个相邻乘数集中叠加于单一格"在数学上仍是极值，但它不是可以摆出来的阵型，而是取决于这一转的抽取，以及那一次换位能否补上关键邻接。

**旋转不产生新符号。** 每次旋转是对既有符号池的抽样：池容量上限 25，每次抽取 20 格，命中率 `P = 20/S`。池中符号越杂，目标符号的期望命中越低。这一设定把方差的主要来源从"旋转"转移到"池的构成"，即转移到玩家的构建决策上。

**租金按周期结算。** 全程 12 期、90 次旋转、累计 4,277 金币。第 1 期 25 金币，第 12 期 777 金币。可用旋转次数随期数放宽（5 转递增至 10 转），但租金增速更快：末期十转对应每转 77.7，而全程均值仅 47.5。中期常见的一种判断偏差是：产出看似充裕，缺口却在扩大——这是数值曲线刻意制造的部分。

**支出分为三类。** 商店提供符号、道具与精华：符号负责产出，道具改变产出的方式，精华直接修改棋盘状态。金币之外另有三种代币——刷新、移除、精华——配额有限，每次使用都构成一次机会成本。

**房东战。** 20 层难度逐层解锁。房东持有血量，本回合产出即伤害。值得注意的是，伤害同时计入"细则"计数器：每累计其最大血量的十分之一，即追加一条附加条款，层数越高单次追加越多。产出提升会同时加快对手的终结与自身规则负担的累积，构成一条自我加压的正反馈回路。

## 设计上的几点观察

**位置被定价在道具上。** 在多数同类作品中，格阵仅承担陈列功能；此处位置直接影响结算，却几乎不可操作——落位由洗牌决定，唯一的位置干预被压缩进一件稀有道具里：一次换位，每转一次。于是"位置"不是玩家的部署自由度，而是一个需要占用道具位去购买的特权。新手与熟练者的差异，从"摆得对不对"变成"值不值得为一次换位腾一个道具位"。

**成长是乘法结构。** 临时乘数逐轮清零，永久乘数连乘累积。曲线因而呈现明显分段：前期平缓，中期出现拐点，后期转为指数增长。设计者用一条乘式替代了常规的线性加成，在不需要扩充内容的条件下获得了节奏。

**不设保底。** 稀有度仅为两套固定档位（符号 68/30/1.5/0.5，道具 56/37.5/5/1.5），自第 5、6 期起冻结，且无保底机制。这是一个有代价的选择：容错降低，方差上升；但每局结果因此可归因于构建而非补偿，对局的可信度得以保留。

**两条指数曲线并行。** 租金与产出同为指数增长，斜率不同。若仅接入符号的基础值与效果声明（不含道具、精华、永久乘数），满池稳态约 13 金币每转，12 期上限约 2,400，低于 4,277 的目标，缺口约 ×1.78。这一结论意味着一件事：纯依附于抽取的策略在数值上不可行，玩家必须在中途介入并修改规则。

**抽象层级递进。** 第一层是计数，第二层是位置，第三层是规则修改。位置这一层没有操作空间，只有读盘：看清这一转的邻接关系，决定要不要动用换位装置。玩家的认知对象最终从赔率表转为规则文本。这种递进在无强制教程的条件下依靠机制自身完成。

**失败可归因。** 对局终止时，绝大多数失因都可定位到具体决策：一次没吃到的邻接、一次多余的刷新、一条未及时到位的乘数。没有无法解释的失败，只有尚未计算的失败。这是机制完备性的一项标志。

## 非功利交互与统计

狗与兔子可以交互：桌面端悬停按帧累加时长，移动端点按折算一次量。累计时长、跳跃次数、兔毛重量、饮酒量——这些与胜负无关的数值被完整记录在档案中，并在特定阈值处触发成就。

一套以概率结算为核心的系统，愿意为无功利交互保留完整的数据通路与成就判定，说明其体验设计的边界并不止于产出优化。

## 运行

仓库内包含一个可完整通关的网页版本：纯静态、可离线运行，上文所述各层机制均在其上实现。

```bash
npm --prefix web install
npm --prefix web run dev      # http://localhost:5173
npm --prefix web run build    # 输出 web/dist，纯静态、相对路径
```

键盘可完成全部操作（`Tab` 聚焦、`Enter`/`Space` 拾起、方向键换位）；进行中的对局连同随机数状态一并持久化，重新打开页面可继续；设置中可降低动画强度。
