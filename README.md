# Luck be a Landlord —— 机制与数值的学术分析

对一个"概率 + 数学"类 Roguelike 的**纯学术机制研究**：把它的经济骨架、概率模型与数值管线形式化，供同类游戏设计与随机性研究参考。

## 合规声明

本仓库**不包含**原作品的任何代码、资源或可执行文件，也不提供反编译工具或反编译产物。

- 只发布**结论**：机制描述、数学公式、伪代码、数值表。
- 反编译产物、提取出的源码、提取/解包脚本，均为作者本地研究材料，已列入 `.gitignore`，不随仓库分发；原始资源 JSON 与邮件正文同理，只保留在被忽略的本地目录 `analysis/data/`，既不入库也不参与构建。
- 文中形如 `文件:行号` 的引用是**追溯标记**，指向作者本地副本，读者无法从本仓库获取该副本。所有结论均可通过 `data/` 下的数值表独立复算（见源码级文档 §10.2）。

## 几条可用结论

- 通关需 **4,277 金币 / 90 次旋转** ≈ **47.5 金币每旋转**（第 12 期瞬时需 77.7）。
- 旋转**不产生新符号**，只是对既有符号池洗牌后取 20 格，命中率 `P = 20/S`。
- 稀有度只有两套固定档位（符号 68/30/1.5/0.5，道具 56/37.5/5/1.5），第 5–6 期冻结，**不存在保底**。
- 产出为**乘法结构**：临时乘数逐轮清空，`permanent_multiplier` 连乘累积，形成指数成长。
- **现行复现模型跑不满 12 期**：只接符号基础值与 `add_effect` 声明（不含道具、精华、永久乘数）时，满池稳态约 **13 金币/旋转**，12 期累计上界 ≈ **2,400 < 4,277**，缺口 **×1.78（样本最优）／×3.64（均值）**。这是模型缺口而非数值不可行——绝对上限（20 格全取最高值 6）仍有 10,800。见 [`analysis/rent-model.ts`](analysis/rent-model.ts)。

细节与出处见 `docs/`。

## 可运行复现台（`web/`）

文档里的结论不应该是"只能读"的断言。`web/` 把它们编译成一个纯静态站点，逐条跑给你看。

```bash
npm --prefix web install
npm --prefix web run dev      # http://localhost:5173
npm --prefix web run build    # 输出 web/dist，纯静态、相对路径
```

页面包含四个部分：

| 模块 | 作用 |
|---|---|
| 对局 | 按分析结论跑 12 期：洗牌命中、租金曲线、旋转供给、稀有度抽卡 |
| 公式实验 | 单格参数化 `value / bonus / multiplier / prev`，逐步展开计算，并与"负值也吃乘数"的错误模型对照 |
| 分布实验 | 洗牌 vs 有放回抽取的蒙特卡洛对比、稀有度抽样回列表、47.52 门槛二分求解、8 邻域扇入 |
| 自检 | 24 条断言实时核对 `data/*.csv`，等价于 `analysis/verify.py` 的输出 |

刻意**不做**的部分也写在页面上：符号专属效果、Fine Print 语义、dud 注入系数——这些在分析文档里列为未完成项，这里不靠记忆补规则。

所有数值在构建时由 `web/scripts/gen-data.mjs` 从 `data/*.csv` 编译，页面不含手抄常量。

### 发布检查

流水线把一个闸门放在部署之前：数据链路、引擎不变量、交互键位、产物自包含，以及租金/产出的可行性推导。任一断言失败即阻止发布。

```bash
npm --prefix web run verify
```

它由两个脚本组成，都入库且可在本地单独跑：

| 脚本 | 检查 |
|---|---|
| `analysis/preflight.ts` | 7 张 `data/*.csv` 是否齐全且未被忽略、行数与编译产物是否一致、effects 引用是否悬空、符号稀有度与图标是否完整、租金单调、权重归一；240 局无头对局验证金币非负、池与棋盘一致、池上限 25；`data-action` 与 handler 是否一一对应；`dist` 是否离线自包含 |
| `analysis/rent-model.ts` | 12 期租金/旋转表自洽（4,277 / 90）、逐期需求曲线、满池稳态产出上界、12 期可行性判定、13 期以后的无尽外推、六档楼层的 ±25 微调是否影响结论 |
